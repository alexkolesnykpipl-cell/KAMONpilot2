# KAMONpilot ᵇʸKC — PWA

Завантажте в корінь репозиторію всі файли та папку `icons`.

## GitHub Pages
У репозиторії відкрийте **Settings → Pages**. У розділі Build and deployment виберіть **Deploy from a branch**, branch `main`, folder `/(root)`, натисніть **Save**. Після публікації GitHub покаже HTTPS-адресу.

## Обмеження прототипу
Чати зберігаються локально у браузері. ШІ відповідає лише після налаштування сумісного Chat Completions API. Генерація зображень і відео не реалізована; вкладення поки позначаються в чаті, але їхній вміст не аналізується. API-ключ у цьому прототипі зберігається у браузері; не використовуйте секретний ключ у публічному або спільному пристрої. Для публічного продукту застосуйте сервер-посередник.
